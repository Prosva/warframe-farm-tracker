  1. Скачай

Вопросы и ответы

Это безопасно?

Скачивай программу только со страницы Releases на GitHub и не бери её с других сайтов. Автоподбор работает через OCR: он распознаёт изображение с экрана.

Отчёт VirusTotalИсходный код на GitHub
Что такое Tesseract и зачем он нужен?

Tesseract это бесплатный движок распознавания текста с открытым исходным кодом. Трекер использует его, чтобы читать цифры с экрана игры. Без него автоподбор не заработает.

Антивирус ругается на файл. Что делать?

Небольшие программы от независимых авторов часто вызывают ложные срабатывания: несколько антивирусов из десятков могут ругаться на чистый файл. Проверку файла можно посмотреть на VirusTotal, а исходный код лежит на GitHub. Если ты скачал файл из Releases, можно добавить папку программы в исключения антивируса.
